# Irma's Pizzelle: Business Plan Files

Launch-planning files for Irma's Pizzelle (revised 2026-11-26). This folder sits alongside the irmaspizzelles.com web app in this repo.

| File | What it is |
|---|---|
| `Irmas_Pizzelle_Product_Presentation.md` | Full product document: overview, recipe, FDA-rounded nutrition, labeling specs, allergens, organic wording, packaging and pricing, cost and margin summary, distribution path (cottage food vs commercial kitchen / Fresh Market), pre-order strategy, risks, next steps |
| `label_copy_design_ready.txt` | Corrected label copy for the designer (front panel, Nutrition Facts for 6- and 12-packs, ingredients, allergens, cottage-food statement) |
| `Irmas_Pizzelle_Cost_Analysis.xlsx` | Live-formula cost model: batch cost per flavor, cost per cookie, 6-/12-pack cost, margins at $8/$10/$12 per dozen, breakeven, kitchen and lab sensitivity |
| `Irmas_Pizzelle_Financial_Model.xlsx` | Rebuilt 5-year model (dummy-data tax/depreciation bug fixed, plain USD) with unit-economics, labor and cottage-cap checks |
| `csv/` | CSV export of every sheet in both workbooks (cached values), so they can be read on GitHub |

The two `.xlsx` workbooks aren't committed here because the GitHub connector only pushes text. The master copies are in `D:\Anna\Irma's`, and the `csv/` folder mirrors them.

Nutrition values are estimates pending a lab test. Packaging Decor container prices are ballpark until quoted.
